⚙️ Configurar Base de Dados
Para sincronização em tempo real, usa o Supabase — gratuito, sem cartão de crédito. Segue os passos abaixo:
1. Vai a supabase.com → "Start your project" → cria conta gratuita
2. Clica "New project" → dá um nome (ex: encomendas) → escolhe região West EU (Ireland) → cria password segura → "Create new project"
3. No menu lateral vai a SQL Editor → clica "New query" → cola o SQL abaixo e clica "Run":
CREATE TABLE IF NOT EXISTS encomendas ( id TEXT PRIMARY KEY, cliente TEXT, categoria TEXT, setor TEXT, subsetor TEXT, prioridade TEXT, prazo TEXT, data_prevista TEXT, estado TEXT, mp TEXT, mp_data TEXT, obs TEXT, updated_at TIMESTAMPTZ DEFAULT NOW() ); CREATE TABLE IF NOT EXISTS transicoes ( id TEXT PRIMARY KEY, order_id TEXT, from_stage TEXT, to_stage TEXT, ts BIGINT, duration_ms BIGINT ); ALTER TABLE encomendas REPLICA IDENTITY FULL; ALTER TABLE transicoes REPLICA IDENTITY FULL;
4. Vai a Project Settings → API → copia o Project URL e a chave anon public
